# React Portfolio

A personal portfolio application built with React. It allows users to view projects, search through existing projects, and add new projects through a form.

## Features

- Display projects using reusable React components.
- Search projects by title, description, and technologies.
- Add new projects using a controlled form.
- Update the project list dynamically.
- Responsive layout for desktop, tablet, and mobile screens.

## Technologies Used

- React
- JavaScript
- CSS
- Vite

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Munenebaariu/react-portfolio.git
```

Navigate into the project directory:

```bash
cd react-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

## Production Build

To create a production build, run:

```bash
npm run build
```
